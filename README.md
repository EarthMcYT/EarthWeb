# EarthWEB site

This is a self-contained static site for GitHub Pages. The HTML includes its images, so no extra asset files are needed.

## Publish with GitHub Pages

1. Create a **public** GitHub repository and upload the contents of this folder to its `main` branch.
2. In the repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
3. The included workflow deploys the site after a push to `main`. The live URL appears in the workflow run and Pages settings.

GitHub Free requires a public repository for GitHub Pages. Publishing makes the site and its source public.
